#  Passa O Controle! — O Novo Modo de Jogar com Amigos

> O **PlayerTwo** é um aplicativo web e serviço de gamificação desenvolvido em **Blazor** que redefine como amigos recomendam e jogam novos títulos. Inspirado em plataformas como a Steam, ele organiza rodízios periódicos (estilo "Amigo Secreto") onde cada participante ganha uma indicação de jogo e precisa cumprir requisitos mínimos de *gameplay* para passar o controle adiante.
